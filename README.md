# ai-resume-analyzer
AI Resume Analyzer using Flask and NLP to match resumes with job descriptions and suggest missing skills.

🚀 Live Demo
👉 https://ai-resume-analyzer-pmwu.onrender.com



📌 Features
📄 Upload resume (PDF format)
📋 Paste job description (from LinkedIn/Naukri/etc.)
🧠 AI-based matching using NLP techniques
📊 ATS score generation
✅ Matched skills detection
❌ Missing skills identification
💡 Smart suggestions to improve resume
🌐 Simple and user-friendly web interface


🛠️ Tech Stack
Python
Flask
HTML, CSS
NLP (TF-IDF / Cosine Similarity / text processing)
PyPDF2 / PDF parsing libraries


📁 Project Structure
ai-resume-analyzer/
│
├── app.py                # Main Flask app
├── parser.py            # Resume text extraction
├── preprocess.py        # Text cleaning
├── skills.py            # Skill matching logic
├── templates/           # HTML files
├── resumes/             # Sample resumes
├── requirements.txt     # Dependencies
└── README.md
